# holbertonschool-binary_trees

Binary tree projects implemented in C as part of the Holberton School curriculum.

## Overview

The repository contains implementations and exercises involving:

- binary trees
- binary search trees
- tree traversal
- node relationships
- tree height and depth
- tree size and balance
- ancestors
- BST operations
- AVL trees
- binary heaps

## Language

The project is implemented in C.

## Purpose

The repository provides practical experience implementing, traversing, inspecting, and manipulating hierarchical data structures.
